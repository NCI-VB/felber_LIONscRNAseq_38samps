This repo contains the raw data and code used to produce the figures in the manuscript

# Durable Tier2 Neutralizing Antibody and Polyfunctional Cytotoxic CD8 T Cell Induction by HIV Env DNA Nanoparticle Vaccination

## Karaliota & Rosati et al. 2026 

### MSD and CBC data

- raw datasets used can be found in input_data/ccbr1394_list_of_rawdatasets.xlsx

- plotted values for each MSD/CBC figure panel can be found in outputs/ccbr1394_list_of_plotted.xlsx

- statistical analysis results can be found in outputs/ccbr1394_list_of_stats.xlsx

- all code can be found in ccbr1394_F89_MSD_ForMS_KCG.Rmd

- the fully rendered report with a tab for each figure panel can be found in outputs/ccbr1394_F89_MSD_ForMS_KCG.html

### scRNAseq data

- raw datasets can be found in GEO (add link)

- code for processing, QC, batch correction, broad clustering, subclustering and trimming by tissue can be found in ccrvb47_LIONscRNAseq_batch123_38samps_QCBatchCorrectionSubclustering_KCG.Rmd

- all downstream analysis code to produce each figure panel can be found in ccrvb47_MSforFigures_FINALNAMES_V2_KCG.Rmd

- plotted values for each scRNASeq figure panel can be found in outputs/ccrvb47_LIONscRNAseq_batch123_38samps_list_of_plotted.xlsx

- 1-vs-All marker DEGs and statistics for each final celltype can be found in batch123_38samps_rpca_tiss_trimmed_ann_FindConservedMarkers_MAST_SCT_minpct0pt1_logfc0pt25_respt4_rpca_ClustersWithSubs.xlsx

- timeDEGs and statistics for each final celltype can be found in ccrvb47_LIONscRNAseq_batch123_38samps_SubclusteringBroad_RPCAtrim_timeDEGsSUMMARY_all3LNor4PBMC_FC1pt19_list_of_degstats.xlsx

- pathway enrichments and statistics for timeDEGs for each final celltype can be found in ccrvb47_LIONscRNAseq_batch123_38samps_SubclusteringBroad_RPCAtrim_timeDEGsSUMMARY_all3LNor4PBMC_FC1pt19_list_of_degEnrichments.xlsx

- the fully rendered report with a tab for each figure panel called ccrvb47_MSforFigures_FINALNAMES_V2_KCG.html will be generated by rendering the ccrvb47_MSforFigures_FINALNAMES_V2_KCG.Rmd (too large to put on github)
