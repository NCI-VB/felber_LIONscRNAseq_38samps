This repo contains the raw data and code used to produce the figures in the manuscript

# Durable Tier2 Neutralizing Antibody and Polyfunctional Cytotoxic CD8 T Cell Induction by HIV Env DNA Nanoparticle Vaccination

## Karaliota & Rosati et al. 2026 

### MSD and CBC data

- raw datasets used can be found in input_data/ccbr1394_list_of_rawdatasets.xlsx

- plotted values for each MSD/CBC figure panel can be found in outputs/ccbr1394_list_of_plotted.xlsx

- statistical analysis results can be found in outputs/ccbr1394_list_of_stats.xlsx

- all code can be found in ccbr1394_F89_MSD_ForMS_KCG.Rmd

- the fully rendered report with a tab for each figure panel can be found in outputs/ccbr1394_F89_MSD_ForMS_KCG.html

### scRNAseq data

- 38 samples were sequenced:

- raw fastq.gz & filtered_feature_bc_matrix.h5 can be found in GEO (add link)

- pipeline code for processing, QC, merging and batch correction can be found in the `pipeline_code` directory
    - `ccrvb47_singleCell_pipeline_241112_hg38` - contains scripts for Batch 3 (1_MC73_09132023, 2_MC73_09192023, 3_MF30_09192023, 4_MF07_09192023)
    - `singleCell_pipeline_20250210_hg38_KCG` - contains scripts for Batch 1, 2, 4, and 5 (remaining 34 samples)

- notes on use of pipeline code for processing, QC, merge, and batch correction, as well as code for broad clustering, subclustering and trimming of clusters by tissue can be found in `ccrvb47_LIONscRNAseq_batch123_38samps_QCBatchCorrectionSubclustering_KCG.Rmd`

- all downstream analysis code to produce each figure panel can be found in `ccrvb47_MSforFigures_FINALNAMES_V2_KCG.Rmd`
    - `bin` directory contains additional scripts referred to in chunks `run_1vsRestDEGs`, `run_timeDEGs` and `CellChatPrep`

- plotted values for each scRNASeq figure panel can be found in `outputs/ccrvb47_LIONscRNAseq_batch123_38samps_list_of_plotted.xlsx`

- 1-vs-Rest marker DEGs and statistics for each final celltype can be found in `ccrvb47_LIONscRNAseq_batch123_38samps_FindConservedMarkers_MAST_SCT_minpct0pt1_logfc0pt25_respt4_rpca_ClustersWithSubs.xlsx`

- timeDEGs and statistics for each final celltype can be found in `ccrvb47_LIONscRNAseq_batch123_38samps_all3LNor4PBMC_FC1pt19_list_of_degstats.xlsx`

- pathway enrichments and statistics for timeDEGs for each final celltype can be found in `ccrvb47_LIONscRNAseq_batch123_38samps_all3LNor4PBMC_FC1pt19_list_of_degEnrichments.xlsx`

- the fully rendered report with a tab for each figure panel called `ccrvb47_MSforFigures_FINALNAMES_V2_KCG.html` will be generated by rendering the `ccrvb47_MSforFigures_FINALNAMES_V2_KCG.Rmd` (too large to put on github)
